GitHub, Discord and a word about Windows' warning; You choose whether to send usage counts.

Pathfinder's code is open on GitHub, and the Discord is open: join it from the app or the website, and find the source on GitHub there too.

- Help has a new "Pathfinder online" card with Discord, GitHub and the website, Settings' Updates card ends with an Open source row, the tray menu has Pathfinder online, and the welcome tour's last step points to the Discord and GitHub.
- The website says what Windows' blue "Windows protected your PC" box means the first time you install: click More info, then Run anyway.

New copies ask whether to send anonymous usage counts, with what's in them shown on the page, and send nothing until you say yes.

- Setup has a new second step, Usage: Yes or No, neither chosen for you, and Next waits for your answer. "See exactly what's sent" shows today's summary before you decide.
- If you already have Pathfinder, your setting stays as it is: Settings → Character and data.
- If you switch usage counts off while you're offline, Pathfinder asks the server again to delete what your copy sent, at each start and every hour, until it has.
- No re-read.
