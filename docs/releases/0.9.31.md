Pathfinder is now code-signed: Windows shows a verified publisher instead of "Unknown publisher" when you install or update.

- The installer, the app, its updater and Pathfinder's own files carry a signature from Microsoft's verified-identity signing service, timestamped so it stays valid.
- Nothing else changed in this version.
