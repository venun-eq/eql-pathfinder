Idle time is counted properly. Time between zoning in and your first kill (a phone call, say) and time since your last kill while a crawl is still open now count as idle, so the live levels-per-hour no longer sinks while you're away. A pause only counts as idle past 3 minutes (it was 60 seconds), so medding, buffing and running to the next pull count as play. Relevel hours read about an hour longer and are closer to the truth. The first start re-reads your logs once (a few minutes).
