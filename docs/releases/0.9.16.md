Second (and later) reincarnations are counted now. The game logs them as 'You have improved Class Reincarnation: X 2', which Pathfinder missed, so a trio with a twice-reincarnated class read as 1.1x XP instead of 1.2x. Relevel times, Ask and the shared numbers use the right XP now. The first start re-reads your logs once (a few minutes).
